    I have a CSV with a size column and I want each circle in a 10×10 grid to take its radius from the matching row.

    Right now every circle gets the same size. Project attached, along with a screenshot of what I see.

    FB Frederik De Bleser NodeBox team 4 days ago

    You're almost there. The Grid node outputs 100 points, but the CSV gives you a list of rows. Put a Lookup node between them and set its key to size:

    import_csv → lookup (key: size) → ellipse.width
grid → ellipse.position

    NodeBox matches the two lists element by element, so the first point gets the first row.
